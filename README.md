# Персональний сайт-візитка (Портфоліо)

Цей проєкт — сучасний, швидкий та адаптивний персональний сайт-візитка, створений за допомогою середовища **Antigravity**.

## 🚀 Особливості проєкту
- **Чисті технології (Vanilla Web):** тільки HTML5, CSS3 та JavaScript (ES6+), без сторонніх бібліотек чи важких фреймворків.
- **Адаптивність (Mobile First & Responsive):** ідеально виглядає на смартфонах, планшетах і широких моніторах.
- **Теми оформлення:** вбудована темна та світла теми з перемикачем і збереженням вибору користувача в `localStorage`.
- **Інтерактивність:** плавний скролінг, відстеження активних розділів меню, мобільне бургер-меню, анімовані смужки інтересу та робоча форма повідомлень.
- **Готовність до GitHub Pages:** сайт оптимізований для моментальної публікації на безкоштовному хостингу GitHub Pages.

## ✏️ Як персоналізувати інформацію під себе

Всі дані легко змінюються у файлі `index.html`:
- **Ім'я та заголовок:** відкрийте `index.html` та замініть `Іван` на своє ім'я або прізвище.
- **Школа та клас:** змініть інформацію в блоках Hero та «Про мене».
- **Хобі та предмети:** відредагуйте текст карток або додайте власні захоплення та відсотки в розділі «Улюблені предмети».
- **Контакти:** вкажіть свої реальні посилання на GitHub, Telegram та Email у розділі `#contact`.
- **Фотографія замість аватара:** замість SVG-блоку в `<div class="avatar-card">` можна вставити свій файл зображення, наприклад:
  ```html
  <img src="photo.jpg" alt="Моє фото" style="width: 100%; height: 100%; object-fit: cover; border-radius: inherit;">
  ```

## 🌐 Покрокова інструкція: Публікація на GitHub Pages

### Варіант 1: Через веб-інтерфейс GitHub (найпростіший спосіб, без встановлення Git)

1. **Створіть акаунт або увійдіть на GitHub:**
   - Перейдіть на [github.com](https://github.com) та увійдіть до свого облікового запису.

2. **Створіть новий репозиторій:**
   - Натисніть кнопку **«+»** у правому верхньому кутку та оберіть **«New repository»**.
   - Введіть назву, наприклад: `portfolio` (або `username.github.io`, якщо хочете, щоб це був ваш головний сайт).
   - Встановіть перемикач на **Public** (Публічний).
   - Поставте прапорець **«Add a README file»** (або залиште порожнім) і натисніть **«Create repository»**.

3. **Завантажте файли сайту:**
   - На сторінці щойно створеного репозиторію натисніть кнопку **«Add file»** ➔ **«Upload files»**.
   - Перетягніть у вікно браузера файли з папки проєкту:
     - `index.html`
     - `style.css`
     - `script.js`
     - `GEMINI.md` (за бажанням)
     - `README.md`
   - Внизу сторінки натисніть зелену кнопку **«Commit changes»**.

4. **Увімкніть GitHub Pages:**
   - У верхньому меню репозиторію відкрийте вкладку **«Settings»** (Налаштування ⚙️).
   - У лівому бічному меню перейдіть у розділ **«Pages»**.
   - У блоці **«Build and deployment»**:
     - **Source:** оберіть `Deploy from a branch`.
     - **Branch:** виберіть гілку `main` (або `master`) та папку `/ (root)`.
     - Натисніть **«Save»** (Зберегти).

5. **Отримайте посилання на готовий сайт:**
   - Зачекайте 1–2 хвилини.
   - Оновіть сторінку налаштувань Pages. Зверху з'явиться зелене повідомлення:
     > *"Your site is live at https://<ваш-логін>.github.io/portfolio/"*
   - Перейдіть за цим посиланням — ваш сайт вже доступний усьому світу! 🎉

### Варіант 2: За допомогою терміналу (Git CLI)

Якщо у вас встановлено Git:

```bash
# 1. Перейдіть до папки проєкту
cd "C:\Users\ivan\.gemini\antigravity\scratch\portfolio"

# 2. Ініціалізуйте Git-репозиторій
git init

# 3. Додайте всі файли та зробіть перший коміт
git add .
git commit -m "Initial commit: personal portfolio website"

# 4. Перейменуйте гілку на main
git branch -M main

# 5. Підв'яжіть віддалений репозиторій GitHub (замініть YOUR-USERNAME та YOUR-REPO)
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git

# 6. Відправте зміни на GitHub
git push -u origin main
```
Після цього увімкніть GitHub Pages у меню `Settings` -> `Pages`, як описано у кроці 4 вище.
